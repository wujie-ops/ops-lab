## 仅在 `tty` 环境下，使用 KVM 安装虚拟机lab纪要

目的：SSH 登录Ubuntu Server主机完成 完成 安装 KVM 实例
环境

主机：Ubuntu Server 22.04.5

KVM

准备镜像：ubuntu-22.04.5-live-server-amd64.iso





首次安装脚本（失败）

```bash
sudo virt-install \
  --name lab-net-test \
  --memory 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/lab-net-test.qcow2,size=20,format=qcow2,bus=virtio \
  --cdrom /var/lib/libvirt/boot/ubuntu-22.04.5-live-server-amd64.iso \
  --network network=kvm-wan,model=virtio \
  --network network=lab-db,model=virtio \
  --os-variant ubuntu22.04 \
  --graphics none \
  --console pty,target_type=serial
```

个人预期：进入安装界面；
实际结果：禁止在一下界面：

```bash
Starting install... Creating domain... | 0 B 00:00:00 
Running text console command: virsh --connect qemu:///system console lab-net-test Connected to domain 'lab-net-test' 
Escape character is ^] (Ctrl + ])
```

查询可知：Ubuntu Server 本身支持通过 serial console 安装，但 `--cdrom` 不适合无图形环境。

一句话：`virt-install` 的 `--cdrom`  参数不合适无图像界面，需要 VNC 客户端 。



第二次安装脚本（失败）

```bash
sudo virt-install \
  --name lab-net-test \
  --memory 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/lab-net-test.qcow2,size=20,format=qcow2,bus=virtio \
  --location /var/lib/libvirt/boot/ubuntu-22.04.5-live-server-amd64.iso \
  --network network=kvm-wan,model=virtio \
  --network network=lab-db,model=virtio \
  --os-variant ubuntu22.04 \
  --graphics none \
  --console pty,target_type=serial \
  --extra-args 'console=ttyS0,115200n8'
```

个人预期：进入安装界面；

实际结果：

```bash
Starting install... 
ERROR Couldn‘t find kernel for install tree. Domain installation does not appear to have been successful. 
If it was, you can restart your domain by running: virsh --connect qemu:///system start lab-net-test otherwise, please restart your installation.
```

#### 问题

`virt-install` 在 `--location` 指向的 ISO 里，**没有找到它预期位置的内核和 initrd 文件**。它按 `os-variant=ubuntu22.04` 的规则去找 Debian Installer 风格的路径（如 `/install/vmlinuz`、`/install/netboot/...`），但 Ubuntu 22.04 **live-server** ISO 用的是 **casper** 布局，内核在 `/casper/` 下。于是自动探测失败。

### 修复方法：显式指定 kernel / initrd

关键参数

```bash
kernel=casper/hwe-vmlinuz,initrd=casper/hwe-initrd
```



第三次安装脚本（TTY 进入安装界面 完成安装）

```bash
sudo virt-install \
  --name lab-net-test \
  --memory 2048 --vcpus 2 \
  --disk path=/var/lib/libvirt/images/lab-net-test.qcow2,size=20,format=qcow2,bus=virtio \
  --location /var/lib/libvirt/boot/ubuntu-22.04.5-live-server-amd64.iso,kernel=casper/hwe-vmlinuz,initrd=casper/hwe-initrd \
  --network network=kvm-wan,model=virtio \
  --network network=lab-db,model=virtio \
  --os-variant ubuntu22.04 \
  --graphics none \
  --console pty,target_type=serial \
  --extra-args 'console=ttyS0,115200n8 ---'
```
